## Правила ведения

- Следующий разбор получает новый уникальный ID и создаётся по [`_template.md`](_template.md).
- Создавайте тематический каталог только одновременно с первым относящимся к нему документом.
- Отделяйте подтверждённые факты от гипотез; не приписывайте системе поведение, не подтверждённое кодом, тестами или диагностикой.
- Не включайте токены, cookies, пароли, приватные ключи, персональные данные или URL с чувствительными параметрами.
- Ссылки и результаты проверок должны быть фактически проверены; unit-тесты не заменяют браузерную или интеграционную приёмку.
- Агент `documentation` запускается только по прямому запросу пользователя либо после его явного подтверждения предложения Orchestrator.

### Вызов агента

- Прямой запрос: «Запусти `documentation` и задокументируй инцидент …».
- Через Orchestrator: Orchestrator сначала описывает scope и спрашивает разрешение на запуск; вызывает агента только после явного согласия пользователя.

## Статусы

- **Investigating** — причина или решение ещё изучаются.
- **Fixed** — изменение внесено, но приёмка решения ещё не завершена.
- **Pending Verification** — есть исправление и автоматические проверки, однако необходимая ручная/интеграционная проверка не завершена.
- **Verified** — заявленные критерии проверены, включая ручные проверки, если они необходимы.
